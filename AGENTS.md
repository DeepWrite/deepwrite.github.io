# DeepWrite Public Teaching Archive Guard

This repository and its GitHub history are public. Treat every tracked path as
world-readable.

- Never add student names, student identifiers, email addresses, submissions,
  drafts, comments, grades, attendance, accommodations, or consent records.
- Keep raw and identifiable teaching material in the authorized private raw
  home under `~/Documents` or another explicitly approved private store.
- Only publish instructor-authored material or student material that has an
  explicit, recorded publication basis and has passed a separate privacy
  review.
- Do not link private section repositories, signed URLs, session-bearing URLs,
  local paths, or institution-only records.
- Before commit, run a privacy scan and inspect the exact staged paths. A
  `.gitignore` rule is an accidental-commit guard, not a storage policy.
- This repository is a legacy public teaching archive. New 2026-2 course
  operations belong in the private `deepwrite-course-platform` source of truth
  and its approved Sites projections.
- Removing sensitive files from the current branch does not remove them from
  Git history. History rewriting, repository visibility changes, and cache or
  search removal requests require explicit user authority.
